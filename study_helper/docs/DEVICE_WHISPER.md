# iPhone·Android 기기 내 음성 변환

강의 녹음을 **휴대폰 안에서** Whisper로 변환한다. 모델 준비 후에는 인터넷·Mac·API 키가 필요하지 않고, 추론 경로에 음성 업로드가 없다. 한국어 다국어 모델 `small-q5_1`(190,085,487바이트, 약 190MB)을 사용한다.

## 사용법

1. 서재 → 강의 녹음으로 들어간다.
2. **오프라인 모델 다운로드**를 누른다. 최초 한 번 인터넷이 필요하다. 이번 개발용 iPhone과 Android 에뮬레이터에는 같은 모델을 미리 설치·검증했다.
3. 녹음하고 종료·저장한 뒤 **이 기기에서 텍스트로 변환**을 누른다.
4. 앱 화면을 유지한다. 진행률을 표시하며 취소할 수 있다. 모델 준비 중에는 잠시 0%에 머무를 수 있다.
5. 결과를 확인·수정하고 **노트로 저장**한다. 기존 Markdown 노트처럼 읽고 편집하며 문제 생성 프롬프트에 사용할 수 있다.

이 기능은 **녹음 완료 후 변환**이다. iOS의 기존 Apple 실시간 받아쓰기는 별도이며 Android에는 아직 실시간 받아쓰기를 붙이지 않았다. Whisper 결과는 별도 임시 결과 필드에 보존하고, 노트 저장을 누르면 현재 받아쓰기로 확정한다. 실패·취소는 원래 음성이나 받아쓰기를 지우지 않는다. 같은 녹음에서 다시 저장하면 같은 노트를 갱신한다.

## 구조

| 담당 | 역할 |
|---|---|
| 공통 Kotlin UI | 모델 준비, 변환 버튼·진행률·취소, 결과 편집 |
| iOS Swift | AAC 읽기, AVAudioConverter 리샘플링, 모델 검증·보관, 파일·노트 연결 |
| Android Kotlin | MediaExtractor/MediaCodec 디코딩, mono 16kHz 변환, 모델 검증·보관, 파일·노트 연결 |
| 공통 C++ `native-whisper` | whisper.cpp 추론·취소·진행률·메모리 사용 제한 |
| Godot | 관여하지 않음 |

iOS는 Metal GPU를 사용하고 Android는 CPU를 사용한다. 모델 SHA-256을 검증한 뒤 설치하며 모델 캐시는 백업에서 제외한다. 음성은 스트리밍 디코딩하여 앱 전용 임시 PCM 파일에 쓰고, 엔진은 최대 60초씩 읽어 처리한다. 처리 후 임시 PCM을 삭제한다. 앱이 강제 종료된 경우 OS 캐시 정리 전까지 임시 파일이 남을 수 있다.

## 현재 한계

- 최대 2시간 녹음. 한 작업씩 실행한다. PCM 임시 파일은 시간당 약 230MB의 여유 공간이 필요하다.
- 앱 화면을 유지해야 한다. 화면 자동 잠금을 잠시 막으며 앱이 백그라운드로 이동하면 취소한다. 백그라운드 장시간 변환은 아직 지원하지 않는다.
- 모바일 모델이므로 큰 서버 모델보다 부정확할 수 있다. 한국어 전문 용어, 수식, 잡음이 있는 실제 강의의 정확도는 추가 확인이 필요하다. 문장 요약이나 문제 자동 생성은 이 기능에 포함하지 않는다.
- 60초 단위 처리 경계에서 문장이 끊길 수 있다. 화자 분리·타임스탬프 편집·모델 선택 UI는 없다.
- GPU/CPU와 메모리를 사용하므로 긴 작업은 발열·배터리 소모가 있다. Android 저사양 기기와 실기기 처리 속도는 아직 검증하지 않았다.
- 취소는 협력적으로 처리한다. 모델을 처음 로드하거나 진행 중 연산이 종료될 때까지 잠시 기다릴 수 있다.
- Android 16kHz 변환은 선형 리샘플링이며 고음역 잡음이 있는 자료에는 추가 품질 개선 여지가 있다.

## 개발 환경 재현

```sh
bash native-whisper/setup.sh

# iOS 엔진 라이브러리: 실제 기기 + Apple Silicon 시뮬레이터
python3 native-whisper/build_ios.py
# 이후 기존 shared XCFramework 및 godotIOS 준비·빌드 순서 실행

# Android: SDK에 NDK 28.2.13676358, CMake 3.22.1 필요
./gradlew :godotAndroid:assembleDebug
```

setup은 whisper.cpp v1.9.4의 `927cfce34f31707e17f2bff35c349632fb9e2c3a`를 확인한다. 원본 코드·라이브러리·모델 바이너리는 `build/`에서 생성하고 Git에는 넣지 않는다. 모델은 앱의 버튼으로 설치하며 다음 SHA-256을 요구한다.

```text
ae85e4a935d7a567bd102fe55afc16bb595bdb618e11b2fc7591bc08120411bb
```

의존성·모델 라이선스는 [THIRD_PARTY_NOTICES.md](../native-whisper/THIRD_PARTY_NOTICES.md)에 기록한다. Mac 서버 실험은 별도 도구로 남아 있으나 앱 기본 화면에서는 숨긴다. 기기 내 변환은 해당 서버를 호출하지 않는다.

## 검증 기록 · 2026-09-27

- **iPhone 17 Pro Max 실기기**: AAC→PCM→Whisper small Q5_1→원본 보존→Kotlin 노트 저장 성공. 11.55초 한국어 합성 음성, 최초 약 14.97초·캐시 준비 후 재검사 약 0.58초 처리. 최종 검사 7개(취소 시 원본 보존 포함) 통과. Mac 서버 종료 상태. [보고서](artifacts/lecture-device-iphone-report.json)
- **Android ARM64 Pixel 4 에뮬레이터**: Wi-Fi·모바일 데이터를 끈 상태에서 같은 흐름 성공. 약 26.42초 처리. 에뮬레이터 수치이므로 실제 Android 휴대폰 속도를 의미하지 않는다. [보고서](artifacts/lecture-device-android-report.json)
- 두 결과 모두 “이진수는 0과 1을 사용합니다”를 인식했다. Apple의 같은 합성 음성 결과에는 “영광이를” 오류가 있었다. 짧은 샘플 하나이며 실제 강의 전체의 정확도 우위를 보장하지 않는다.
- iOS·Android 빌드 성공, 공통 UI 테스트 44개 통과, Android Lint 오류 0개. 모델 다운로드 파일의 해시 검증 경로는 iPhone 실기기에서 실행했다. 두 기기의 모델 설치는 개발용 파일 전송으로 수행했으므로 앱 버튼을 통한 장시간 다운로드·중단·재시도는 추가 수동 검사 대상이다.

DEBUG 검사: iOS는 Documents에 `lecture-korean-fixture.m4a`와 모델을 놓고 `--lecture-device-probe`로 실행한다. Android는 debug 전용 `WhisperProbeActivity`에 fixture와 모델을 준비한다. 마이크를 열지 않으며 임시 서재에만 노트를 저장한다.
