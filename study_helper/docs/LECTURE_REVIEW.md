# 강의 받아쓰기 검토

녹음 중 실시간 받아쓰기는 초안이다. iOS와 Android에서 녹음을 저장한 후, 자동 재인식 설정이 켜져 있고 모델이 준비되어 있으며 앱 화면이 열려 있으면 전체 녹음을 기기 내 Whisper로 다시 처리한다. 모델이 없거나 앱이 배경에 있으면 녹음은 보존하고 수동 재시도 안내를 표시한다. 배경 이동 시 진행 중인 변환은 취소되며 자동 재개되지는 않는다. 기존 녹음은 `전체 음성 다시 인식`으로 처리한다. 현재 최대 2시간이다.

## 사용 흐름

1. 강의 녹음 화면에서 `과목 용어 · 강의 자료 참고 설정`을 연다.
2. 과목명·전문용어·핵심 문장을 최대 2000자 붙여 넣는다. 현재 선택한 참고 문구는 기기에 저장되어 다음 재인식에도 사용된다. PDF 자동 추출 기능은 아니다.
3. `녹음 종료 후 자동으로 전체 재인식`을 켠다. 모델 최초 다운로드 이후 음성 인식은 기기 안에서 실행된다.
4. 결과에서 `교정본 편집`, `실시간 초안`, `원음 확인`을 비교한다. 원음 확인에는 재인식 결과와 타임스탬프가 표시되며 해당 구간 1초 전부터 재생한다.
5. 확인한 교정본을 노트로 저장한다. 실시간 초안과 재인식 결과는 별도로 보존된다. 재인식해도 직접 저장한 교정본을 자동으로 덮어쓰지 않는다.

## 검토 표시의 의미

평균 토큰 확률이 0.6 미만이거나 숫자가 들어간 구간을 `확인 권장`으로 표시한다. 이는 검토 우선순위를 제시하는 휴리스틱이며, 오류 탐지나 정확도 보장은 아니다. 표시가 없는 문장도 틀릴 수 있다. 용어 참고 문구는 Whisper 초기 프롬프트로 전달되며 강제 치환하지 않는다. 별도의 언어 모델에 의한 의미 교정이나 수식 검증은 수행하지 않는다.

네이티브 엔진은 60초 단위로 오디오를 처리하고, 각 청크의 시작 시간을 합산하여 전체 녹음 기준 구간 시작·종료 시간을 저장한다. 초안은 `transcript`, 재인식 결과는 `whisperTranscript`, 사용자 교정본은 `reviewedTranscript`, 타임스탬프는 `segments`에 저장한다. 기존 녹음 JSON도 읽을 수 있다. PC 앱에는 기존 녹음 기능이 유지되며 이번 자동 재인식 기능은 iOS·Android에 연결했다.

- JVM 70개 통과: 참고 문구 길이 제한, 녹음 중 변경 차단, 초안과 교정본 분리, 타임스탬프 및 검토 표시 포함.

- iOS·Android·PC 빌드 성공. Android의 새 흐름 실기기 검증과 실제 33분 강의 전체 재인식 정확도 평가는 아직 수행하지 않았다.
