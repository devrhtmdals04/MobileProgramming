# Study Helper 로컬 웹

PC에서는 저장소 루트의 **`Study Helper 웹 실행.command`**를 더블클릭합니다. Python 3가 있는 Mac에서 로컬 서버와 기본 브라우저가 열립니다. Node.js, Gradle, 별도 패키지 설치는 필요하지 않습니다.

터미널 실행:

```sh
python3 webApp/server.py
```

주소는 **http://127.0.0.1:8765**이며 이 컴퓨터에서만 접속할 수 있습니다. 터미널에서 Ctrl+C로 종료합니다. 이미 서버가 실행 중이면 실행 파일을 다시 열어 기존 서버의 브라우저 화면으로 이동합니다. 포트가 사용 중이면 `python3 webApp/server.py --port 8766`으로 실행할 수 있습니다.

## 사용 순서

1. **자료 가져오기**에서 PDF(12MiB 이하), 마크다운, TXT 또는 Study Helper 문제 JSON을 선택합니다.
2. **API 설정**에 OpenAI 키를 입력합니다. 서버 메모리에만 보관하며 페이지를 새로고침해도 유지됩니다. 서버를 종료하면 지워집니다. `OPENAI_API_KEY` 환경변수로도 전달할 수 있습니다.
3. **요약 만들기**를 누르면 원본 PDF를 OpenAI Responses API에 보내고, 생성 중인 요약을 마크다운 서식으로 표시합니다. 완료된 결과만 로컬 저장소에 저장합니다. 기존 요약은 실패·중지 시 유지됩니다.
4. **노트 수정**에서 제목과 내용을 고칠 수 있습니다. PDF 페이지 근거 링크는 원본 PDF 탭의 해당 페이지를 요청합니다. 실제 페이지 이동 지원은 브라우저 PDF 뷰어에 따라 다릅니다.
5. 문항 수·난이도·서술형 포함 여부를 정하고 **문제 생성하기**를 선택합니다. PDF가 있으면 요약이 아닌 PDF 원본을 사용하며, 마크다운 자료는 노트 원문을 사용합니다.
6. **문제 풀기**에서 답을 제출하면 서버에서 객관식을 채점합니다. 서술형은 모범 답안·채점 기준을 보고 직접 평가합니다. **오답 복습**에는 현재 문제 모음의 가장 최근 답이 틀린 문제만 표시합니다.
7. **내보내기**로 노트 `.md` 또는 문제 `.quiz.json`을 저장해 기존 모바일·데스크톱 앱으로 가져올 수 있습니다.

AI 기능에는 인터넷과 API 키가, Drive 동기화에는 인터넷과 Google 로그인이 필요합니다. 저장된 자료 읽기·편집·문제 풀이·오답 복습에는 API 호출이 없습니다. 키 입력은 로컬 서버로만 전달되고, 서버가 OpenAI에 인증합니다. 키는 HTML 응답·브라우저 저장소·데이터베이스·로그에 저장하지 않습니다. API 모델 기본값은 `gpt-5.4-mini`입니다. 설정의 후보 목록에서 GPT-5.4 Mini(기본 추천), GPT-5.6 Luna(비용 절약), GPT-5.6 Terra(품질 중시), GPT-5.6 Sol(복잡한 자료)을 선택하면 권장 용도와 표준 입력·출력 요금이 표시됩니다. 용도는 앱의 추천이며 실제 품질은 자료에 따라 비교해 보세요. 요금은 2026-10-05 공식 모델 문서 기준으로 100만 토큰당 USD입니다. 긴 입력·페이지 이미지·추론량에 따라 실제 비용이 달라지며 API 계정별 사용 권한을 확인해야 합니다. 다른 모델은 ‘다른 모델 직접 입력’으로 지정할 수 있습니다.

## 저장과 범위

파일 기반 서재를 연결한 현재 환경에서는 `~/Desktop/2026-2/학습`의 PDF·노트·문제 파일을 직접 읽고 수정합니다. `webApp/.local-data/study.sqlite3`에는 파일 경로·자료 ID·풀이 기록·동기화 기준을 저장하며 자료 본문을 중복 저장하지 않습니다. 연결 설정은 `.local-data/library.json`입니다. 백업에는 학습 폴더와 `.local-data`가 모두 필요합니다. 연결 설정 없는 새 저장소는 기존 DB 저장 방식을 유지합니다.

기존 PC 앱의 Google 설정과 공유 폴더를 사용해 Drive와 연동합니다. 모바일에서도 같은 계정·Drive 폴더를 선택합니다. 웹의 풀이 기록은 기기별로 유지되며 Godot 게임과 녹음 기능은 웹에 포함하지 않습니다. 페이지 번호와 정답의 사실성은 원본과 비교해 확인해야 합니다. 마크다운 뷰어는 제목·강조·목록·표·인용·코드를 지원하며 원본 HTML과 외부 이미지는 실행·로딩하지 않습니다.

python3 -m unittest discover -s webApp/tests -v
node --check webApp/static/app.js  # 개발 검증용, 앱 실행에는 Node.js 불필요

구현 기준: [OpenAI PDF 입력](https://developers.openai.com/api/docs/guides/file-inputs), [Responses 스트리밍](https://developers.openai.com/api/docs/guides/streaming-responses).

## 초기 폴더 가져오기 방식 (2026-10-05, 연결 설정 없는 저장소)

Lightnote의 과목 카드, 자료별 한 줄 요약, 복습·오답 현황 구성을 참고해 웹 서재를 개편했습니다. 첫 화면에서 과목을 고르면 주차별 자료 카드가 표시됩니다. 검색과 학습 상태 필터로 정리 전 자료나 오답이 남은 자료를 찾을 수 있습니다.

- **폴더에서 자료 모으기**: 브라우저에서 선택한 폴더의 PDF·MD·TXT·문제 JSON을 사본으로 가져옵니다. `학습/정보보안/02주차/강의.pdf`는 정보보안 과목, 02주차로 분류합니다. 주차 폴더가 없으면 파일의 바로 위 폴더를 과목 후보로 사용합니다. 분류는 추정이므로 자료 화면의 **수업 분류**에서 수정할 수 있습니다.
- 지원하지 않는 파일과 숨김 폴더·node_modules·build·dist는 제외합니다. 최대 1,000개씩 가져오며 실패한 파일은 알립니다. 가져오기만으로 AI 요청을 보내지는 않습니다.
- 같은 상대 경로와 같은 내용은 다시 가져와도 중복 저장하지 않습니다. 내용이 변경된 파일은 기존 편집 내용과 풀이 기록을 보존하기 위해 별도 자료로 추가합니다. 현재 상대 경로에는 선택한 최상위 폴더 이름까지 포함되며, 경로 이름이 달라지면 별도 자료로 처리합니다.
- 새로 가져온 MD·TXT는 원문을 따로 보관합니다. 요약을 편집하거나 재생성해도 **원본 텍스트**에서 원문을 볼 수 있고 AI 요청도 원문을 사용합니다. 업데이트 전에 가져온 텍스트 자료의 과거 원문은 복원할 수 없으므로 기존 노트를 사용합니다.
- 기존 웹 자료·요약·문제·풀이 기록은 유지되며 과목이 없는 자료는 **미분류**에 표시됩니다. PDF·이미지 등에서 과목을 AI로 추론하거나 여러 자료를 한 정리본으로 합치는 기능은 아직 없습니다.

아래 파일 기반 서재를 연결하면 학습 폴더 감시와 직접 파일 저장을 사용합니다. 학습 폴더 안의 파일은 다시 가져올 필요가 없습니다.

검증: 서버 테스트 15개(기존 DB 이전, 분류 수정, 중복 재가져오기, 변경 파일 보존, 원문 기반 생성, 최신 답안 기준 오답 집계 포함) 통과. Chrome에서 과목·주차 표시, 폴더 가져오기, 분류 수정·새로고침 후 보존, 중복 처리와 모바일 폭 화면을 확인했습니다. 기존 요약·출제·풀이·오답 복습·편집·내보내기도 모의 AI 응답으로 검증했습니다.

## AI와정보보안 수업 통합 정리

가져온 AI와정보보안 자료를 바탕으로 1~4주차 정리본과 복습 문제 27문항을 추가했습니다. 각 주차의 **수업 통합 정리** 카드를 먼저 보여주고, 기존 PDF·필기·문제는 **원본 자료**에서 펼쳐볼 수 있습니다.

- 1주차: CIA와 AI·디지털 자산 보호, 6문항
- 2주차: 계정·세션·권한·로그 등 시스템 보안, 8문항
- 3주차: 네트워크 흐름과 공격 유형 구분, 8문항
- 4주차: 제공된 퀴즈 풀이 메모 범위의 복습, 5문항. 강의 전체 요약이 아닙니다.

정리본은 학습 목표·핵심 개념·비교표와 예시·확인할 내용·복습 체크로 구성합니다. `(자료 1 · PDF 10쪽)` 버튼으로 해당 PDF를 열고, 필기를 열었을 때는 **통합 정리본으로 돌아가기**를 사용할 수 있습니다. PDF 쪽수 이동 지원은 브라우저 뷰어에 따라 다릅니다. 서술형은 모범답안·기준을 보고 자기평가합니다.

이번 정리본은 Codex가 로컬 PDF와 기존 필기를 검토해 작성했습니다. 외부 GPT API를 호출한 결과가 아니며 API 비용은 발생하지 않았습니다. 앱에서 나중에 재생성할 때는 연결된 PDF와 원문 필기를 함께 GPT API에 전달합니다. 원본 자료는 덮어쓰지 않습니다.
