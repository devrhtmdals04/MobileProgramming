## 구성

1주차는 물리량·단위, 전하·에너지 계산, 옴의 법칙, 전력의 고정 조건, 수동 부호 규약, KCL·KVL, 직렬·병렬, 전압 분배, 노드 해석, 테브난을 다룹니다.

2주차는 C·L의 연속 조건과 직류 정상상태, RC·RL 시상수, 충전·방전 비율, 저항 변화 비교, 저장 에너지, 목표 전압 도달 시간, 디지털 입력 보장 한계를 다룹니다.

문항은 개념 확인과 짧은 계산을 섞었습니다. 보기 3개와 정답 1개, 해설, 근거 문장을 포함합니다. 계산 조건·단위·초기값을 명시해 그림 없이도 풀 수 있도록 했습니다. 수식은 앱의 현재 뷰어에서 읽을 수 있는 일반 텍스트로 표기했습니다.

## 원본과 재구성

아래 **마크다운 필기**를 읽고 재구성했습니다. PDF 전체를 새로 검토하거나 강의 전체를 전사한 결과는 아닙니다.

- `1주차/1주차.md`
- `1주차/기호정리.md`
- `2주차/2주차_강의정리.md`
- `2주차/RC_RL_방전속도_비교.md`

원문의 주요 조건과 강의정리의 보정을 유지했습니다. 일부 간단한 계산 예제와 객관식 문항은 이 샘플을 위해 새로 작성했습니다. 각 `sourceQuote`는 **함께 제공한 샘플 노트의 실제 문장·공식**입니다. 원본 강의 문장을 그대로 인용했다는 뜻은 아닙니다. 외부 AI API로 자료를 전송하지 않았습니다.

## 앱에서 사용

연결된 아이폰의 Study Helper에 두 노트와 두 문제 모음을 추가했습니다. 기존 노트는 유지했습니다.

1. **노트 서재**에서 ‘디지털시스템입문’을 검색하거나 해당 주차 노트를 엽니다.
2. **문제 모음**에서 1주차 또는 2주차 묶음을 엽니다.
3. 문제·정답·해설·근거를 확인한 후 **이 문제로 게임 시작**을 선택합니다.

한 판에는 선택한 묶음에서 **무작위 3문항**이 출제되고 보기도 섞입니다. 전체 12문항은 문제 미리보기에서 확인할 수 있습니다.

다른 기기로 가져갈 때는 `.md`를 노트 가져오기에서, `.quiz.json`을 문제 파일 가져오기에서 선택합니다. 이 폴더의 JSON은 기기마다 노트 ID가 달라지는 점을 고려하여 `sourceNoteId`를 비워 두었습니다. 아이폰에 직접 추가한 사본에는 함께 저장한 노트의 ID를 연결했습니다. 앱 코드와 기본 샘플은 변경하지 않았으므로 다른 신규 설치에 자동으로 포함되지는 않습니다.

## 검증 · 2026-09-27

실제 Kotlin `MarkdownNotes`, `QuizFiles`, `StudyService`로 확인했습니다.

- 노트 2개 파싱 및 두 문제 파일의 스키마 검증 통과.
- 24문항의 모든 근거 문자열이 해당 노트에 존재함을 확인.
- 전체 문항을 3개씩 나누어 8세션 생성, 보기 섞기 후 **24문항 모두 정답 채점** 및 결과 집계 확인.
- 게임 공개 세션에 정답 키와 원문 근거가 미리 노출되지 않음을 확인.

형식·채점 검증과 별도로 단위 환산과 계산 정답을 검토했습니다. 앱의 스키마 검증 자체가 학습 내용의 사실성을 자동 판정하는 것은 아닙니다.
