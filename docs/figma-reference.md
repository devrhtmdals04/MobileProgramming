# Figma 참고 및 확인할 사항

**확정 기준:** 기존 Figma 작업물을 전체 화면 UI의 디자인 기준으로 사용한다. 김민성이 Compose 화면과 ViewModel 코드를 구현한다. Figma 디자인은 Kotlin ViewModel을 대신하는 코드가 아니며, 상태·이벤트 로직은 Android에서 별도로 작성한다.

원본: https://www.figma.com/design/vUavTwW7VuTMCQojbNkrJT/모프?node-id=0-1

초기화 시 연결된 Figma 전용 도구가 제공되지 않았고 웹 도구로도 파일 내용을 열 수 없었다. 따라서 node 0:1의 실제 자식 구조·컴포넌트·색상·간격·텍스트·프로토타입 링크는 확인하지 못했다. 현재 UI는 사용자 제공 화면 목록으로 만든 골격이며 Figma 재현 완료가 아니다. 다운로드나 디자인 파일 생성·수정은 수행하지 않았다.

| 제공 화면 | 목적 | 현재 대응 | UI-01 확인 대상 |
|---|---|---|---|
| 로그인 | 사용자 진입 | AuthScreen, 이메일/비밀번호, Mock 진입 | 로고·입력·가입 링크·오류 문구 |
| 동아리 홍보 피드 | 모집 정보 탐색 | HomeScreen, 홍보 카드 | 카드 정보·이미지 비율·하단 탐색 |
| 카테고리 탐색과 검색 | 관심 동아리 발견 | SearchScreen, 검색/카테고리 칩 | 실제 카테고리·검색 위치·결과 없음 |
| 동아리 수요조사 및 개설 요청 | 신규 동아리 수요 표현 | RequestScreen, 이름·목적 | 필수 입력·내역·상태·수요조사 범위 |
| 홍보글 상세 | 모집 정보 확인 | ClubScreen, 홍보/동아리 정보 | 상세 구성·모집 기간·CTA 위치 |
| 관리자 문의 | 1:1 대화 | ChatScreen/ChatListScreen | 말풍선·시간·전송 상태·문의 대상 |
| 동아리 가입 신청 | 가입 의사 제출 | RequestScreen(clubId), 자기소개 | 실제 입력 항목·완료 화면·중복 신청 |

임시 디자인: 보라색 `#6554C0`, 연한 배경 `#FAF8FF`, 기본 Material 3 Typography, 텍스트 기반 탭. 이는 원본에서 추출한 값이 아니다. 이미지와 아이콘 에셋을 임의로 원본처럼 만들지 않았다.

### 다음 확인 체크리스트

- [ ] 팀원에게 Figma 열람 권한 부여 및 실제 프레임 ID 기록
- [ ] 컬러·타이포·간격·모서리 토큰 확정
- [ ] 하단 탭 이름/순서와 상세 화면 이동 비교
- [ ] 로그인·가입·채팅·개설·가입 신청 필수 필드 확인
- [ ] 로딩·빈 데이터·오류·권한 부족 상태 보완
- [ ] 작은 화면·키보드·큰 글꼴·스크린리더 읽기 순서 확인
- [ ] UI 차이는 Issue와 화면 비교 이미지로 기록

김민성은 전체 화면의 디자인 비교·공통 컴포넌트·상태·검증 문구를 담당한다. 고승민은 인증·채팅·개설의 데이터 계약과 오류 의미를 제공하고 화면을 리뷰한다. 디자인 접근 지연 시 Mock 개발은 계속하고, 원본 확인이 필요한 항목은 UI-01의 미완료 조건으로 유지한다.
