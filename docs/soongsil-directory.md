# 숭실대학교 동아리 목록 연결

Firebase 모드의 MopeApplication은 SoongsilClubRepository를 사용한다. Mock/Emulator는
기존 MockClubRepository를 유지한다. 학교 로그인이나 비공개 API를 사용하지 않는다.

출처: 숭실대학교 동아리연합회 https://clubunion.ssu.ac.kr/
공개 목록 API: https://clubunion.ssu.ac.kr/api/club/list?page=0&size=100
공식 소개: https://clubunion.ssu.ac.kr/clubs/{id}

2026-11-18 확인 시 77개/7개 분과이며, 숫자를 앱에 고정하지 않고 실제 목록과 다음 페이지를
조회한다. 홈의 카드는 공식 소개로 표시하고 탐색에서 이름·분류를 검색한다. 분류 필터는
전체 원본 목록에서 구해 검색 결과가 비어도 옵션을 유지한다. 네트워크 실패는 오류/재시도를
표시하며 샘플 목록으로 바꿔 성공처럼 보이지 않는다. 새로고침/재진입 시 다시 조회하며
백그라운드 주기 수집이나 Firebase 자동 복제는 하지 않는다.

동아리명·분과·공식 소개 링크만 가져온다. 대표자 이름·전화번호·개인 연락처·사진·소개문 전체는
수집하지 않는다. 기존 설명 필드는 분과에 기반한 안내 문장으로 채우고 모집 여부를 추정하지 않는다.
공식 목록의 학교 대표자를 그루 관리자 계정으로 임의 연결하지 않는다. adminId는 비워 두며
문의·앱 가입은 관리자 계정 연결 전까지 비활성화한다. 공식 소개 링크로 연락/가입 안내를 확인한다.

공식 사이트가 사용하는 공개 API이며 제휴 API 계약은 아니다. 사이트의 API 형식 변경·중단 시
앱의 파서를 갱신해야 한다. Android 실기 실행 환경에서 목록 조회와 한글 이름 검색을 검증했다.
